# Sourabh Pawar — Software Engineer Portfolio

A responsive dark-premium portfolio built with React, CSS and Vite.

## 1. Requirements
- Node.js (LTS)
- VS Code
- Internet connection for Google Fonts

## 2. Run locally
1. Extract this ZIP file.
2. Open the extracted `sourabh-software-engineer-portfolio` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## 3. Build for production

```bash
npm run build
npm run preview
```

The production website is generated in the `dist` folder.

## 4. Personalize before publishing
Open `src/App.jsx` and update:
- `your.email@example.com` with your professional email.
- LinkedIn placeholder with your actual LinkedIn profile URL.
- Trusty Tails description, technology tags and GitHub project URL.
- Internship duration and exact role/company details, if needed.
- Add a real resume PDF in `public/` and add a download link only after the file is ready.

Review every project description and link to ensure it accurately reflects your own contribution.

## 5. Publish
You can deploy the project using Vercel or Netlify. Import the GitHub repository, use `npm run build` as the build command and `dist` as the output directory.

## Tech stack
React · Vite · CSS · Responsive layout
